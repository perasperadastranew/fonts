# Библиотека шрифтов Perasperadastra — правила для работы

Сайт fonts.perasperadastra.ru — один файл `index.html` (GitHub Pages из ветки main).
Данные шрифтов живут прямо в нём: `const FONTS`, `FEAT`, `MET`, `HIST`, `SETS`, `CAPS`, `STUB`.
Веб-версии шрифтов — `web/<slug>/*.woff2` (урезанный набор знаков), оригиналы — архивы `<slug>.zip` в ветке `files`.

## Перед каждым пушем — автопроверка

```sh
pip install fonttools brotli numpy freetype-py   # один раз
python3 tools/check.py
```

- ❌ ошибки — исправить до пуша. Пушить с ошибками нельзя.
- ⚠️ предупреждения — посмотреть шрифт глазами. Если всё в порядке: `python3 tools/check.py --accept`, тогда оно станет известным и больше не будет мешать.
- Если менялись FONTS, классы или подборки — пересобрать данные MCP-сервера: `python3 mcp/build_data.py` и закоммитить `mcp/fonts.json`.

## Добавление шрифта — что проверить

1. В каждом начертании есть полная кириллица (прописные и строчные). Начертания без кириллицы в FONTS не добавлять. Шрифт только из прописных — добавить в `CAPS`.
2. Класс — один из пяти: Гротеск, Антиква, Акцидентный, Моно, Рукописный.
   - Моно — только моноширинные шрифты для кода и таблиц. Моноширинный пиксельный дисплейный шрифт — Акцидентный.
   - Акцидентный — дисплейные, капительные, пиксельные, декоративные. Текстовое семейство на 4+ начертания с нормальными пропорциями — Гротеск или Антиква.
3. Файл внутри архива — действительно этот шрифт (имя в файле совпадает), не чужой и не «Extras»/«Elements».
4. Не дубль: проверка сравнивает форму «Ж» со всей библиотекой.
5. Демо-версии с водяными знаками не добавлять.
6. `catalog.json` и `mcp/fonts.json` обновлены вместе с `index.html`.
7. Подборки (`SETS`) ссылаются только на существующие названия.

## Порядок в каталоге («Сначала лучшие»)

- `PICKS` в index.html — витрина, отобранная глазами (~80 шрифтов). Они идут первыми, вперемешку по классам, каждый день в новом порядке. Чтобы поднять шрифт на первый экран — добавить его название в `PICKS`.
- Остальные — по `QS`: оценка проработки шрифта внутри своего класса (глифы, кернинг, OpenType, языки, ₽/№/«», число начертаний, лицензия). Одно семейство не идёт подряд, каждый следующий шрифт семейства опускается ниже.
- Новому шрифту без оценки в `QS` достаётся 40 из 100 — середина.
