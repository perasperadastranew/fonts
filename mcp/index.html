Как подключить

Выберите, где вы работаете. Входить и ставить ключи нигде не нужно: сервер открытый.

ШАГ 1

Откройте коннекторы

На claude.ai или в приложении Claude: Настройки → Коннекторы (Customize → Connectors).

Открыть коннекторы ↗
ШАГ 2

Добавьте свой коннектор

Нажмите «+» → «Добавить свой коннектор» (Add custom connector). Название: Шрифты Perasperadastra. Адрес:

https://pada-fonts-mcp.perasperagram.workers.dev/mcp
ШАГ 3

Сохраните и пользуйтесь

Нажмите «Добавить». Если спросят про вход, выберите «без входа». В новом чате включите коннектор в меню «+» и попросите подобрать шрифт.

Работает на сайте, в десктопном и мобильном приложениях Claude. На бесплатном тарифе можно добавить один свой коннектор, на платных — сколько угодно. В командных тарифах коннектор добавляет владелец организации.
ОДНА КОМАНДА

Добавьте сервер в терминале

Выполните в терминале, Claude Code подхватит сервер в следующей сессии:

claude mcp add --transport http pada-fonts https://pada-fonts-mcp.perasperagram.workers.dev/mcp
ПРОВЕРКА

Убедитесь, что он на месте

Внутри Claude Code наберите /mcp: в списке должен быть pada-fonts со статусом connected. Чтобы сервер был доступен во всех проектах, добавьте флаг --scope user.

Claude Code умеет запускать команды, поэтому он сам скачает и установит шрифт в систему, если попросить: «поставь Dela Gothic One на мой Mac».
ВАРИАНТ 1 · КОМАНДА

Codex CLI

Выполните в терминале:

codex mcp add pada-fonts --url https://pada-fonts-mcp.perasperagram.workers.dev/mcp

Проверить: codex mcp list, а внутри Codex — /mcp.

ВАРИАНТ 2 · КОНФИГ

Через config.toml

Добавьте в ~/.codex/config.toml:

[mcp_servers.pada-fonts]
url = "https://pada-fonts-mcp.perasperagram.workers.dev/mcp"
Конфиг ~/.codex/config.toml общий для Codex CLI, расширения в IDE и десктопного приложения: настроив один раз, вы получите шрифты везде.
ШАГ 1

Откройте MCP-серверы

В десктопном приложении: Настройки → MCP-серверы. В расширении для VS Code / Cursor: шестерёнка → MCP settings.

ШАГ 2

Добавьте сервер

Add server → имя pada-fonts → тип Streamable HTTP → адрес:

https://pada-fonts-mcp.perasperagram.workers.dev/mcp
ШАГ 3

Перезапустите

Сохраните и нажмите Restart, чтобы расширение подхватило сервер.

Что умеет

Пять инструментов, которые нейросеть вызывает сама, когда вы просите про шрифты.

SEARCH_FONTS

Подбор под задачу

Обычным текстом или фильтрами: класс, назначение, настроение, подборки, курсив, вариативность.

GET_FONT

Карточка шрифта

Автор, начертания, для чего подходит, похожие шрифты и полный текст условий автора.

GET_FONT_CSS

Код для сайта

Готовый @font-face с woff2: только нужные веса, сразу в лендинг или прототип.

GET_DOWNLOAD

Установка

Архив и команды для macOS, Windows и Linux, чтобы шрифт появился в Figma и Adobe.

LIST_FILTERS

Справочник

Все классы, назначения, настроения и тематические подборки библиотеки.

Попробуйте попросить

Нажмите на карточку — запрос скопируется, вставьте его в чат.

Про лицензии

Сервер всегда сообщает статус лицензии, а нейросеть получает указание проверять его перед коммерческим использованием.

Открытая

OFL, CC0, Apache, MIT и похожие. Можно в коммерции и для клиентов. Таких шрифтов 653.

Условия автора

Бесплатно, но на условиях конкретного автора. Сервер отдаёт полный текст условий из архива.

Уточняются

Для учёбы и экспериментов. В клиентских и коммерческих проектах лучше выбрать другой шрифт.
