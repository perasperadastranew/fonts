Подключение

Входить и вводить ключи не нужно.

  1. 1

    Откройте плагины

    На claude.ai или в приложении Claude: раздел Plugins в левом меню.

    claude.ai/plugins ↗
  2. 2

    Добавьте свой коннектор

    Нажмите Add → Add custom connector. Название — Шрифты Perasperadastra, адрес:

    https://pada-fonts-mcp.perasperagram.workers.dev/mcp
  3. 3

    Подтвердите

    Нажмите Continue, оставьте No sign-in и нажмите Add. Коннектор сразу работает в новых чатах.

Работает на сайте, в десктопном и мобильном приложениях. На бесплатном тарифе можно добавить один свой коннектор. В командных тарифах коннектор добавляет владелец организации.

  1. 1

    Добавьте сервер

    Выполните в терминале:

    claude mcp add --transport http --scope user pada-fonts https://pada-fonts-mcp.perasperagram.workers.dev/mcp
  2. 2

    Проверьте

    Внутри Claude Code наберите /mcp — в списке появится pada-fonts.

Claude Code может выполнять команды, поэтому сам скачает и установит шрифт в систему, если попросить.

  1. 1

    Добавьте сервер

    Выполните в терминале:

    codex mcp add pada-fonts --url https://pada-fonts-mcp.perasperagram.workers.dev/mcp
  2. 2

    Или через конфиг

    Добавьте в ~/.codex/config.toml:

    [mcp_servers.pada-fonts]
url = "https://pada-fonts-mcp.perasperagram.workers.dev/mcp"
  3. 3

    Проверьте

    codex mcp list в терминале или /mcp внутри Codex.

Файл ~/.codex/config.toml общий для Codex CLI, расширения в IDE и десктопного приложения: настроив один раз, вы получите шрифты везде.

  1. 1

    Откройте MCP-серверы

    В приложении: Настройки → MCP-серверы. В расширении для VS Code или Cursor: шестерёнка → MCP settings.

  2. 2

    Добавьте сервер

    Add server, имя pada-fonts, тип Streamable HTTP, адрес:

    https://pada-fonts-mcp.perasperagram.workers.dev/mcp
  3. 3

    Перезапустите

    Сохраните и нажмите Restart.

Возможности

Нейросеть вызывает их сама, когда вы просите про шрифты.

Подбор

Поиск обычным текстом или по фильтрам: класс, назначение, настроение, подборки, курсив, вариативность, число начертаний.

Карточка шрифта

Автор, начертания, для чего подходит, похожие шрифты и полный текст условий автора.

Код для сайта

Готовый @font-face с woff2 — только нужные веса, сразу в лендинг или прототип.

Установка

Архив и команды для macOS, Windows и Linux, чтобы шрифт появился в Figma и Adobe.

Справочник

Классы, назначения, настроения и тематические подборки библиотеки.

Лицензии

Сервер всегда сообщает статус лицензии.

Открытая

OFL, CC0, Apache, MIT и похожие. Можно в коммерции и для клиентов.

Условия автора

Бесплатно, но на условиях конкретного автора. Сервер отдаёт полный текст условий.

Уточняются

Для учёбы и экспериментов. В клиентских проектах лучше выбрать другой шрифт.
