Репозиторий: https://github.com/perasperadastranew/fonts (публичный), GitHub Pages из ветки `main`.

**Сначала прочитай `CLAUDE.md`** — там обязательные правила (проверка перед пушем, добавление шрифтов,
ветка `files` с архивами). Здесь — карта проекта, состояние и что осталось.

## Карта

| Что | Где |
|---|---|
| Весь сайт (HTML+CSS+JS, данные) | `index.html` (~900 КБ, одна страница, роутинг по `#/...`) |
| История и «похожие» для страницы шрифта | `page.json` (грузится лениво, см. `pageData()`, версия `PAGEV`) |
| Веб-версии шрифтов (урезанный набор знаков) | `web/<slug>/*.woff2` |
| Оригиналы для скачивания | ветка `files`: `<slug>.zip` (≈900 МБ, только через `tools/upload_zip.py`) |
| Кэш шрифтов в браузере | `sw.js` (только `web/**/*.woff2`) |
| Поиск по картинке | `find.js` (замеры), `find/match.json` (эталоны, `tools/build_match.py`) |
| Проверка перед пушем | `tools/check.py` (+ `tools/known.json` — принятые предупреждения) |
| Вынос данных страницы шрифта | `tools/split_page_data.js` |
| MCP-сервер «Для ИИ» (Cloudflare Worker) | `mcp/` (`build_data.py` → `fonts.json`, `src/index.js`) |
| Ежедневная проверка на GitHub | `.github/workflows/check.yml` |

### Главное внутри index.html (искать по имени)
- Данные: `FONTS` (строка = `[имя, класс, вариативный, minW, maxW, кол-во начертаний, курсив, slug, файлы, лицензии-файлы, лицензия, автор, источник]`), `FEAT`, `MET`, `QS`, `PICKS`, `SETS`, `CAPS`, `STUB`, `WDTH`, `BASED`.
- Загрузка шрифтов: `loadFont(f, only)` — на странице шрифта все файлы; в каталоге 2 начертания (400 и ~700); `only` = один вес (шапка, отсеки), `'i'` — курсив.
- Роутер: `route()`; страница шрифта `fontPage(f)`; каталог `cardHTML`, `renderGrid`.
- Обложки/композиции: объект `T` (шаблоны), `compose(el, f, tpl, pal)`, `DIR` (какие шаблоны у какого класса), `TPL_BY_SLOT`. Хорошие «показывающие шрифт» шаблоны: `spec`, `scale2`, `waterfall`, `weights`, `editorial`. Трюковые (`glyph`, `rhythm`, `catalogcard`, `marking`, `halftone`, `orbit`) Саша забраковал — не возвращать в ротацию.
- Геометрия (раздел 03): `T.blueprint` + `blue()`; кириллица (раздел 09): `.cyr2`, `.cyp`, `.cyr`.
- Шапка «ШРИФТЫ»: `logoInit()`, набор узких шрифтов `LOGO_NARROW`, оптический трекинг по профилям глифов.
- Генератор пар: `pairsFor`, `lineFor`, `wordFor`, `collage*`, `pixel*`, разбор команды `#/review` (`PREV_GOOD`/`PREV_BAD`).

## Как проверять локально

```sh
pip install fonttools brotli numpy freetype-py playwright && python3 -m playwright install chromium
python3 tools/check.py          # обязательно, 0 ошибок
python3 -m http.server 8765     # сайт на http://localhost:8765
```
Сайт берёт шрифты с `https://fonts.perasperadastra.ru/web/...` (константа `REPO`). Без сети / для проверки
незалитых шрифтов в Playwright подменяй эти запросы локальными файлами (`page.route('https://fonts.perasperadastra.ru/**', ...)` → `web/...`).
Смотри результат глазами (скриншоты) на разных классах: гротеск, антиква, акцидентный, моно, рукописный, узкий/капительный (например Inter, Yeseva One, Anton, JetBrains Mono, Shnobel, Amatic SC).
